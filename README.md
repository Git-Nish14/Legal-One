# Legal One

Legal One is a web application designed to streamline legal services by providing a platform for users, lawyers, and administrators. The application includes authentication, case management, and legal document handling.

## Features

- **Three Authentication Systems**: Users, Lawyers, and Admins
- **Secure User Authentication**: JWT-based authentication with cookies
- **Case Management**: Create, update, and track cases
- **Legal Document Handling**: Upload and manage legal documents
- **Role-Based Access Control**: Different access levels for Users, Lawyers, and Admins
- **Real-time Updates**: Using WebSockets for instant notifications
- **Responsive UI**: Built with Next.js for optimal performance

## Tech Stack

- **Frontend**: Next.js (App Router)
- **Backend**: Node.js, Express
- **Database**: MongoDB (with Prisma ORM)
- **GraphQL API**: TypeGraphQL with Apollo Server
- **Authentication**: JWT stored in cookies
- **Real-time Communication**: Socket.io

## Usage

- Users can sign up, log in, and create legal inquiries.
- Lawyers can respond to cases and manage legal documents.
- Admins oversee the platform and manage users.
